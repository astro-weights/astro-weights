Run headers split their keys into config (decide the outputs) and provenance (where and when). `check_headers` now compares config keys only, so HTTP arms under different served names or URLs no longer need `--ignore-header`; new `config_hash`, `CONFIG_KEYS`, `PROVENANCE_KEYS`, and an `arm_keys` argument for arms on one server. `run_header` and `run_header_http` also record a run id, K, concurrency, library version and commit, numpy version, GPU model and count, llama.cpp build info, vLLM version and declared `serving_flags`. `run_header_http` records the served name as `served_model` instead of `model`. New `astro_weights.eval.Verdict` schema for `verdict.json`.
